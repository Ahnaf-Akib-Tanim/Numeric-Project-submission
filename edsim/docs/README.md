## Building

### Report (full LaTeX source included)

```bat
cd report
build            ::  runs pdflatex -> bibtex -> pdflatex x2, then copies to C_02.pdf
```

or by hand:

```bat
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

`report/` contains `main.tex`, `references.bib`, `figures/` (9 vector PDFs),
`build.bat` and a `Makefile`. It needs `acmart.cls` and
`ACM-Reference-Format.bst`, both standard in TeX Live and MiKTeX.

### Slides

```bat
cd slides
build            ::  pdflatex twice -> presentation.pdf
```

> **Note on `slides/beamer.cls`.** Your MiKTeX installation's own
> `beamer.cls` has been **overwritten by somebody's example presentation** —
> the file at
> `…\MiKTeX\tex\latex\beamer\beamer.cls` is a 154-line slide deck titled
> *"Beamer Presentation for CSE200"*, not the beamer class. The rest of the
> beamer package (130 files) is intact, so the deck builds against a genuine
> `beamer.cls` placed in this folder, which shadows the broken one. Nothing
> outside this project was modified.
>
> To repair it permanently: MiKTeX Console → *Packages* → search `beamer` →
> uninstall, then reinstall. After that you can delete `slides/beamer.cls`.

## Where the numbers come from

Every figure in both documents is a vector PDF copied straight out of
`../results/figures/`, and every number in the report was read from
`../results/tables/*.csv` and `../results/raw/*.manifest.json` — the output of

```bash
python scripts/run_all.py          # seed 20250402, 100 replications
```

To refresh everything after a new run: re-run the pipeline, re-copy the
figures, then rebuild. `../results/PROVENANCE.md` records the exact command
behind every artefact.
